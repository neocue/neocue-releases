# NeoCue for macOS

A native Mac workspace for files, terminals, and Git.

[Download NeoCue](https://github.com/neocue/neocue-releases/releases/latest/download/NeoCue.zip) · [Release notes](https://github.com/neocue/neocue-releases/releases)

Requires macOS 14 or newer on Apple Silicon. Downloads become available when the first release is published.

## Install

1. Download and unzip `NeoCue.zip`.
2. Drag `NeoCue.app` into `/Applications`.
3. Open NeoCue.

Published builds are signed with Developer ID and notarized by Apple. NeoCue uses Sparkle to check for updates and lets you review the changelog before choosing **Install and Restart**. You can also choose **Check for Updates…** from the app menu.

Each release includes its changelog and a `SHA256SUMS` file for checking the ZIP download. Previous versions remain available on the [releases page](https://github.com/neocue/neocue-releases/releases).

This repository hosts distribution files and changelogs. Product information: [neocue.app](https://neocue.app).
